# RoadWatch Traffic Sign Phase 2

This Kaggle GPU job audits the 82-class Vietnamese sign dataset, renders a Human
Quality Gate sample, fine-tunes the sign detector and trains a second speed-value
classifier from speed-sign crops.

Required attached inputs:

- `lapnguyen2003/traffic-sign-detection-vietnam`;
- a private RoadWatch model/input containing `yolo11s_vietnam_traffic.pt`;
- `maitam/vietnamese-traffic-signs` as an OCR-gated 40/50/60/80 supplement;
- `meowmeowmeowmeowmeow/gtsrb-german-traffic-sign` as CC0 classifier-train
  support only; it is excluded from Vietnamese validation metrics;
- optionally `roadwatch_sign_hard_negatives` generated by
  `scripts/build_sign_hard_negatives.py`.

Version 1 must run with `QUALITY_GATE_APPROVED=0`. Review
`roadwatch_sign_phase2/quality_gate/`. Submit a new version with
`QUALITY_GATE_APPROVED=1` only after boxes, classes and split leakage pass review.

Do not use the VNTS publisher's train/test lists for metrics: adjacent video
frames occur in both splits. The pipeline replaces them with a contiguous-frame
group split and runs OCR on every supplementary numeric crop. A supplementary
crop is never trusted from its published class ID alone.

The job outputs a detector checkpoint plus a crop classifier for numeric speed
values. Locked RoadWatch video regressions remain local and must not be attached as
training data.

## Version 11 quality-gate policy

Version 10 reached 96.59% on the clean Vietnamese seed validation set, but it
also proved that the publisher's `10` directory is heavily contaminated with
40 km/h signs. Version 11 therefore:

- applies the checked-in `manual_speed_curation.json` decisions from the V10
  ranked contact sheets to recover clearly visible 80/90 crops;
- excludes numeric 10 from the promoted classifier label set;
- routes reviewed real 10 km/h crops plus synthetic 10 signs into `unknown`;
- keeps `unknown` non-numeric at runtime, so it cannot generate a false speed
  banner or TTS announcement;
- requires every manual entry to match an actual crop and renders a separate
  `speed_unknown_{train,val}.jpg` contact sheet for review.

Numeric 10 support can only be restored after a separate, independently
reviewed real-domain validation set passes the same class minimums. This is an
intentional fail-safe degradation, not an attempt to claim unsupported coverage.

Version 13 is the recorded approval baseline: all automated gates passed,
clean-seed validation reached 395/410 (96.34%), class 90 reached 50 train and
15 validation crops, and `unknown` reached 314 train and 4 validation crops.
The official fine-tune must emit `quality_gate_approval.json` containing both
this baseline and the freshly recomputed gate evidence before training begins.

Version 14 exposed a reproducibility edge case: temporary bootstrap acceptance
changed class 90 from 50 to 49 crops, so the gate correctly stopped before
training. The follow-up makes the bootstrap DataLoader deterministic and adds
five visually reviewed class-90 crops, producing a safety margin without
lowering the required 50/15 threshold.
